# Chrome 탭 오디오 녹음기 1.2.1

사용자가 선택한 Chrome 탭의 소리만 WebM/Opus 파일로 녹음합니다. 마이크, 다른 탭의 소리, Windows 알림음은 포함하지 않습니다.

## 주요 기능

- 현재 열린 Chrome 탭 중 녹음 대상을 직접 선택
- 소리가 재생 중인 탭에 `🔊` 표시
- 녹음 일시정지 및 재개
- 일시정지 시간을 제외한 실제 녹음 경과 시간 표시
- 현재 녹음 중인 탭 제목 표시
- 5초마다 녹음 조각을 브라우저의 로컬 IndexedDB에 저장
- Chrome 비정상 종료 후 저장된 구간 복구
- 정상 다운로드가 완료되면 임시 복구 데이터 자동 삭제
- 64kbps WebM/Opus로 장시간 음성 녹음 용량 절감
- 최초 설치 시에만 이 GitHub 프로젝트 페이지를 한 번 표시

## 기존 버전 업데이트

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 기존 확장 프로그램 카드의 새로고침 버튼을 누릅니다.
3. 새로고침이 안 되면 기존 항목을 제거한 뒤 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `zep-tab-audio-recorder` 폴더를 선택합니다.

## 사용 방법

1. Chrome 도구 모음에서 확장 프로그램 아이콘을 누릅니다.
2. 목록에서 녹음할 탭을 선택합니다. `🔊` 표시는 현재 소리가 나는 탭입니다.
3. **녹음 시작**을 누릅니다.
4. 필요하면 **일시정지**와 **녹음 재개**를 사용합니다.
5. **종료·저장**을 누릅니다.
6. 파일은 `다운로드\ZEP_Recordings` 폴더에 자동 저장됩니다.

팝업을 닫아도 녹음은 계속되며, 다시 열면 현재 상태와 경과 시간이 표시됩니다.

## 비정상 종료 후 복구

Chrome 또는 확장 프로그램이 비정상 종료되면 마지막 최대 5초를 제외한 녹음 조각이 로컬에 남습니다. 다음에 확장 프로그램 팝업을 열면 **복구 가능** 상태가 표시됩니다.

- **복구 파일 저장**: 저장된 조각을 하나의 WebM 파일로 결합해 다운로드
- **복구본 삭제**: 저장된 조각을 완전히 삭제

정상 다운로드가 끝난 녹음의 임시 조각은 자동으로 삭제됩니다.

## 개인정보 보호

녹음, 탭 제목과 URL, 복구 조각은 사용자의 기기에서만 처리됩니다. 외부 서버 요청, 분석 도구, 광고 코드, 추적 코드가 없습니다. 자세한 내용은 배포 자료의 개인정보처리방침을 확인하세요.

## 참고

- Chrome 116 이상이 필요합니다.
- `chrome://` 페이지와 Chrome 웹 스토어 같은 내부 페이지는 녹음 목록에서 제외됩니다.
- 선택한 탭을 닫거나 오디오 스트림이 종료되면 녹음 파일 저장을 시도합니다.
- 녹음 종료 시 장시간 녹음 조각을 결합하므로 저장 완료까지 시간이 걸릴 수 있습니다.
- 강의 녹음과 보관에 관한 제공자의 정책을 확인하세요.
