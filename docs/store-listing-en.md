# Chrome Web Store listing (English)

## Name

Chrome Tab Audio Recorder

## Short description

Record audio from one selected Chrome tab locally, with pause and elapsed-time controls.

## Detailed description

Chrome Tab Audio Recorder is an audio-only recording tool for online lectures, webinars, meetings, and other browser-based audio. It saves the selected tab's sound as a local WebM/Opus file.

Key features

- Choose the recording source from your open Chrome tabs
- See which tab is currently playing audio
- Record only the selected tab, excluding the microphone and system notification sounds
- Pause and resume recording
- Display the actual recorded time excluding pauses
- Continue recording after the popup is closed
- Save the completed recording automatically to the downloads folder
- No external upload, account, advertising, analytics, or tracking

All audio data is processed only on your device and is never sent to the developer or an external server.

Chrome internal pages, DRM-protected content, and content restricted by site policy cannot be recorded. Check the content provider's terms and applicable laws before recording.

## Single purpose

Record audio from a Chrome tab selected by the user as a local file and provide recording controls.
