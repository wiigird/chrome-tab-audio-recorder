# Chrome 网上应用店介绍（简体中文）

## 名称

Chrome 标签页音频录制器

## 简短说明

仅在本地录制所选 Chrome 标签页的声音，并支持暂停和录制时长显示。

## 详细说明

Chrome 标签页音频录制器是一款纯音频录制工具，适用于在线课程、网络研讨会、会议及其他浏览器音频。它会将所选标签页的声音保存为本地 WebM/Opus 文件。

主要功能

- 从已打开的 Chrome 标签页中选择录制来源
- 标记当前正在播放声音的标签页
- 仅录制所选标签页，不录制麦克风和系统通知声音
- 暂停和继续录制
- 显示扣除暂停时间后的实际录制时长
- 关闭弹出窗口后继续在后台录制
- 录制结束后自动保存到下载文件夹
- 无外部上传、账号、广告、分析或跟踪

所有音频数据仅在您的设备上处理，不会发送给开发者或任何外部服务器。

Chrome 内部页面、受 DRM 保护的内容以及受网站政策限制的内容无法录制。录制前请确认内容提供方的条款及适用法律。

## 单一用途

将用户选择的 Chrome 标签页音频录制为本地文件，并提供录制控制功能。
