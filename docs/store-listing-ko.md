# Chrome 웹 스토어 등록 문안

## 이름

Chrome 탭 오디오 녹음기

## 짧은 설명

선택한 Chrome 탭의 소리만 로컬로 녹음하고 일시정지와 녹음 시간 표시를 지원합니다.

## 상세 설명

Chrome 탭 오디오 녹음기는 온라인 강의, 웨비나, 회의 및 브라우저 기반 음성을 로컬 WebM/Opus 파일로 저장하는 오디오 전용 녹음 도구입니다.

주요 기능

- 열린 탭 목록에서 녹음 대상을 직접 선택
- 현재 소리가 나는 탭 표시
- 선택한 탭의 소리만 녹음하고 마이크와 시스템 알림음 제외
- 녹음 일시정지 및 재개
- 일시정지 시간을 제외한 실제 녹음 시간 표시
- 팝업을 닫아도 백그라운드 녹음 유지
- 녹음 종료 시 다운로드 폴더에 자동 저장
- 외부 업로드, 계정, 광고, 분석 및 추적 없음

모든 오디오 데이터는 사용자의 기기 안에서만 처리되며 개발자나 외부 서버로 전송되지 않습니다.

Chrome 내부 페이지, DRM으로 보호된 콘텐츠 또는 사이트 정책상 캡처가 제한된 콘텐츠는 녹음할 수 없습니다. 녹음 전에 콘텐츠 제공자의 이용약관과 관련 법규를 확인해 주세요.

## 카테고리

도구

## 언어

한국어

## 단일 목적 설명

사용자가 선택한 Chrome 탭의 오디오를 로컬 파일로 녹음하고 녹음 제어 기능을 제공하는 것입니다.

## 권한 사유

- tabs: 열린 탭 제목과 URL을 표시해 녹음 대상을 선택하고 파일 이름을 만드는 데 필요합니다.
- tabCapture: 사용자가 선택한 탭의 오디오 스트림을 캡처하는 핵심 권한입니다.
- offscreen: 팝업이 닫혀도 MediaRecorder를 유지하고 오디오 파일을 만드는 데 필요합니다.
- downloads: 완성된 WebM 파일을 사용자 다운로드 폴더에 저장하는 데 필요합니다.

## 개인정보 공개 항목

- 웹사이트 콘텐츠: 선택 탭의 오디오를 사용자가 요청한 녹음 파일로 만들기 위해 로컬 처리
- 웹 이용 기록: 열린 탭 제목과 URL을 녹음 대상 선택 UI에 표시하기 위해 로컬 처리
- 개인 통신: 사용자가 회의나 통신 탭을 선택한 경우 오디오에 포함될 수 있으나 개발자에게 전송되지 않음

데이터 판매, 광고 사용, 신용평가 사용, 외부 전송 및 개발자의 데이터 접근은 없습니다.
